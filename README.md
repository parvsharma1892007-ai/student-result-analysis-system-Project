# student-result-analysis-system
# 🎓 Student Result Analysis & Management System

## 📌 Project Description

This project is a Python-based system that analyzes student quiz results using MySQL database. It integrates multiple subjects like DBMS, COA, and Statistics into one application.

---

## 🚀 Features

* 🔐 Login System (User Authentication)
* 📊 Database Analysis (Average, Highest, Lowest Scores)
* ⚙️ CPU Scheduling Simulation (FCFS)
* 📈 Statistical Analysis (Mean, Median, Mode, Std Dev)
* 🏆 Student Ranking System

---

## 🛠 Technologies Used

* Python
* MySQL
* MySQL Connector (Python Library)

---

## ⚙️ Installation Steps

### 1. Install Python

Download from: https://www.python.org

### 2. Install MySQL

Install MySQL Server & Workbench

### 3. Install Required Libraries

```bash
pip install mysql-connector-python
```

## 🗄️ Database Setup

1. Open MySQL Workbench
2. Run the file:

```
parv_project.sql
```

3. Ensure database name:

```
parv_project
```
